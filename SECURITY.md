# Security and antivirus notes

This mod patches and calls game functions in memory because Crimson Desert does not expose an official mod API for this feature. Antivirus software can treat low-level hooking behavior as suspicious even when a mod is not malicious.

Verify the downloaded release ZIP and ASI against the SHA-256 hashes in [README.md](README.md). Do not download renamed copies from untrusted mirrors.

If reporting a suspected security issue, do not include credentials or personal data in a public issue. Describe the affected file, its hash, download source, and scanner result.
