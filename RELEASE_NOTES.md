# PrivateStorageAnywherePLUS — Crimson Desert 2.00

This is the tested final Crimson Desert 2.00 compatibility release, based on build AX.

## Highlights

- Restores PrivateStorageAnywherePLUS on Crimson Desert 2.00 without the startup crash affecting the older compatibility build.
- F4 opens configurable Private Storage.
- F5–F9 open the five housing chests, each fixed at 1,000 slots.
- `PrivateStorageSlots=0` restores normal F4 capacity.
- `PrivateStorageSlots=1000` makes F4 total capacity exactly 1,000, including purchased expansions.
- F11 reloads the INI; settings are also re-read when a panel opens.
- All six panels were opened and closed in the passing test, with no crash or freeze.

## Install

Download `PrivateStorageAnywherePLUS-CD-2.00-FINAL.zip`. Import the ZIP into DMM, or copy the ASI and INI to the game's `bin64` directory. Disable every other Private Storage Anywhere entry first.

This is for Crimson Desert 2.00 only.
